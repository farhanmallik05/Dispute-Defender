# Dispute Defender (Main Project Directory)

> **Dispute Defender**: Open-source AI agent that triages PayPal disputes, builds the evidence packet, and submits it after one-click merchant approval.

This directory will contain the complete implementation of Dispute Defender:
- **Next.js 14+ / TypeScript** fullstack web application.
- **AG Grid**-powered Dispute Command Center & Analytics Dashboard.
- **PayPal Agent Toolkit & Server SDK** integration for order and shipment tracking lookups.
- **Custom PayPal Disputes REST API client** for multipart evidence submission (`POST /v1/customer/disputes/{id}/provide-evidence`).
- **Zero-Trust PII Redaction Engine** protecting buyer personal data.
- **Vercel AI SDK** structured triage agent generating evidence dossiers and legal rebuttals.
- **Render Workflows** durable execution pipeline.
- **Drizzle ORM & SQLite** persistence and immutable audit logs.
